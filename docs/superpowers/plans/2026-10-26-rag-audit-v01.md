# RAG Audit Workbench 首版实现计划

> 面向 AI 代理的工作者：使用 subagent-driven-development，在同一会话按任务实现。用户已批准设计与执行，不重复请求执行方式确认。

**目标：** 交付可安装、可浏览、可导入旧记录并真正执行源撤回的离线审计工具。

**架构：** Python 标准库承担协议、BM25、审计、回放、SQLite 存储和报告；Streamlit 为可选页面。统一 JSON 协议贯穿 CLI、SDK 和网页；完整重建作为撤回正确性的独立参照。

**技术栈：** Python 3.11+、SQLite、pytest、Streamlit；GitHub Actions 验证 Windows 与 Linux。

## 共享协议

schema_version 为 `1.0`。bundle 保存 sources、artifacts、runs、metadata。来源字段为 source_id、revision、title、text、sha256、trust、status。source_id 与 revision 不包含 @；稳定引用为 source_id@revision。trust 只能由外部字段给出，正文不能提升信任。status 为 active/revoked/quarantined。

artifact 保存 artifact_id、kind、source_refs、dependencies，以及可选 start/end/text/metadata。跨度以 Python Unicode 字符计数。run 保存 execution、backend、query、config、index_sha256、candidates、context_ids、context_text、answer、answer_kind。未调用生成器时 answer 为 null，answer_kind 为 not_generated。

backend.build_bundle(sources, queries, config=None) 返回 bundle；backend.retrieve(bundle, query, config=None) 返回 run。replay.replay(bundle, withdrawn_refs, queries=None) 返回干预报告，包含 replayed_bundle、queries 对比、invalidation、validation。schema.ensure_bundle 只负责结构；完整性问题由 audit_bundle 定位。

audit.audit_bundle(bundle) 返回 findings、counts、coverage、passed。importers.load_input(content, filename) 返回统一 bundle，历史结果必须标记 imported_history。

service.Workbench 提供 ingest/get_bundle/list_bundles/audit/replay/get_report/list_reports/verify_ledger。入口共享该服务，避免网页与 CLI 各自实现业务。

## 验收边界

首版不声称执行了 Microsoft GraphRAG 重建，不把规则决策当作 LLM 生成，不把历史导入当成新实验。图适配与真实生成器属于批准设计中的后续里程碑。源撤回改变结果只说明指定运行条件下的影响；恶意判断需独立证据。
